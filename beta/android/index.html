pickture on Android

Until pickture is on the Play Store, you install the app directly as a file.

Get the APK · 121 MB

Takes about 2 minutes · Using an iPhone?

  1. 1

    Download

    Download the file on your Android phone and open it.

    Tap Open

    Get the APK · 121 MB →
  2. 2

    Allow the install

    The first time, Android asks about your browser: open settings and switch it on.

    Tap Allow from this source

  3. 3

    Install

    If Play Protect warns you, tap “More details” – it only appears because pickture isn’t on the Play Store yet.

    Tap Install anyway

  4. 4

    Get started

    Done! For bigger updates, download the file here again and install it over the old one – your data stays.

On a computer? Scan the code with your phone.

Found something? Tell us in the app under Settings → Help → Report a bug, or email support@getpickture.app.
